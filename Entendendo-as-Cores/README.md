# 🎨 Entendendo as Cores

### Paleta de Cores
Criar  bons esquemas de cores é combinar e equilibrar matiz, tom, sombra e temperatura.
Harmonia de cores e teoria das cores oferecem algumas fórmulas que podemos usar para iniciar paleras de cores.

### Cor 
É o termo geral que usamos para descrever cada matiz, tonalidade e tom.

### HUE

Refere-se à família de cores dominante da cor específica que estamos  analisando. Branco, preto e cinza, geramente não são referidos como matiz ou cor.

![Imagem sobre HUE](/assets/HUE.png)

### Matiz
Um matiz é qualquer matiz ou mistura de cores puras com apenas branco adicionado. A matiz clareia a cor mas não a torna mais brilhante.

![Imagem sobre Matiz](/assets/Matiz.png)
