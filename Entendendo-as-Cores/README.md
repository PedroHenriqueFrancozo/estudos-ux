# 🎨 Técnica de Cores

### 1. Hue (Matiz) - A Cor Pura
O Hue é a "raiz" da cor (Vermelho, Azul, Amarelo).

- **Dica:** Branco, Preto e Cinza são Acromáticos (sem cor/matiz). Por isso dizemos que eles não têm Hue.

![Imagem sobre HUE](/assets/HUE.png)

### 2. Tint (Tonalidade ou "Matiz" no seu texto) - Cor + Branco
O Tint clareia a cor (ex: Vermelho + Branco = Rosa). ele não aumenta o brilho no sentido de intensidade, ele apenas torna a cor mais pálida ou pastel.

![Imagem sobre Matiz](/assets/Matiz.png)

### 3. Tone (Tom) - Cor + Cinza
O tom é o segredo das paletas sofisticadas.

- **Por que usar:** Adicionar cinza remove a "vibração" agressiva da cor pura. Em interfaces (UI), usar tons para criar elementos que não cansam os olhos do usuário (como fundos ou áreas secundárias).
