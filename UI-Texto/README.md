# 🔠 Figma: Ferramenta de Texto
A ferramenta de texto permite inserir e estilizar conteúdo escrito, sendo essencial para criar a hierarquia visual e a legibilidade do projeto.

### 1. Como acessar

- **Atalho:** Tecla `T`
- **Ação: `*` Clique único:** Cria uma caixa de texto que cresce horizontalmente conforme você digita (Auto Width).
- **Clique e arraste:** Cria uma caixa de texto com largura fixa. O texto "quebra" para a próxima linha quando atinge a borda (Fixed Size).

### 2. Painel "Text" (Propriedades Principais)
Ao selecionar um texto, o painel à direita libera as configurações:

**Font Family:** Escolha da fonte (ex: Inter, Roboto, Montserrat).
**Weight (Peso):** Variações como Light, Regular, Medium, Bold, Black.
**Size (Tamanho):** Definido em pixels (px).
**Line Height (Entrelinha):** O espaço vertical entre as linhas. Fundamental para a legibilidade.
**Letter Spacing:** O espaço entre as letras.
**Paragraph Spacing:** O espaço entre parágrafos (evita que você precise dar "Enter" duas vezes).
