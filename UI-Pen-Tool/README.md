# ✒️ Figma: Pen Tool e Vector Networks
Diferente de outras ferramentas, a Pen Tool não cria apenas formas estáticas; ela desenha caminhos (paths) através de pontos de ancoragem.

### 1. Como acessar

- **Atalho:** Tecla `P`
- **Ação:** Clique para criar pontos retos; clique e arraste para criar curvas (alças de Bézier).

### 2. O diferencial: Vector Networks
No Figma, a Pen Tool não é apenas linear. Pode conectar um ponto a vários outros, criando uma "teia" ou rede.

- Em outros programas, um ponto só se conecta a dois outros. No Figma, um ponto pode ter três ou mais conexões, facilitando muito o desenho de ícones complexos.
