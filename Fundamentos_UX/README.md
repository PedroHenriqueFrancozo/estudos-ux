# 🏗️ As Disciplinas dos Fundamentos de UX
Para criar uma experiência completa, o designer precisa equilibrar estas cinco áreas:

### 1. Design de Interação (IxD)
Foca na relação entre o usuário e o produto. O objetivo é que as interações (cliques, gestos, transições) sejam lógicas e fluidas.

- **Foco:** O comportamento. Como o sistema responde ao comando do usuário?

### 2. Interface do Usuário (UI)
É a camada onde a interação acontece. Envolve a criação de menus, botões, ícones e todos os elementos que permitem ao usuário controlar o sistema.

- **Foco:** O meio de contato. É o "painel de controle" do usuário.

### 3. Design Visual
É a estética do produto. Usa cores, tipografia e imagens para criar uma identidade e guiar a atenção do usuário (Hierarquia Visual).

- **Foco:** A aparência. Transmite a personalidade da marca e gera desejo e confiança.
