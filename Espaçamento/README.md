# 📏 O Poder do Espaçamento

### 1. Tipos de Espaçamento

- **Macro White Space:** O espaço entre grandes elementos da página (margens laterais, espaço entre seções). Serve para dar "respiro" ao layout e separar temas diferentes.
- **Micro White Space:** O espaço entre elementos menores (entre linhas de texto, entre ícone e rótulo, entre letras). É vital para a legibilidade.

### 2. Espaçamento Tipográfico (Vertical e Horizontal)

- **Leading (Entrelinha):** O espaço vertical entre as linhas de um parágrafo.
    - **Regra de bolso:** Use entre 1.4 a 1.6 vezes o tamanho da fonte para textos longos.
- **Tracking (Espaçamento entre letras):** Ajuste global do espaço entre as letras de uma palavra ou bloco.
- **Kerning:** Ajuste individual entre dois caracteres específicos (ex: o espaço entre um 'A' e um 'V').

### 3. Lei da Proximidade (Gestalt)
O espaçamento define relações. Elementos que estão **próximos** são percebidos como parte de um mesmo grupo. Elementos afastados são percebidos como diferentes.

    Se o título está muito longe do parágrafo, o cérebro do usuário demora mais para entender que eles estão conectados.

### 4. Escalas de Espaçamento (Grids)
Para manter a consistência, designers não usam números aleatórios. Geralmente usa-se a **Regra do 8pt** (8, 16, 24, 32, 40, 48... pixels). Isso garante que o layout pareça harmônico em qualquer tela.
