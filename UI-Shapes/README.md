# 🎨 Figma: Criação e Manipulação de Shapes
As formas geométricas (Shapes) são os blocos de construção de qualquer interface. No Figma, elas são vetoriais, o que significa que não perdem qualidade ao serem redimensionadas.

### 1. As Formas Básicas (Menu de Shapes)

- **Rectangle (Retângulo) `R`:** A forma mais usada para botões, cards e fundos.
- **Line (Linha) `L`:** Usada para divisores e separadores de conteúdo.
- **Arrow (Seta) `Shift + L`:** Útil para fluxogramas ou indicação de direção.
- **Ellipse (Elipse/Círculo) `O`:** Usada para avatares de perfil, ícones e botões circulares.
- **Polygon (Polígono):** Por padrão cria um triângulo, mas você pode alterar o número de lados no painel lateral.
- **Star (Estrela):** Usada para sistemas de avaliação (rating).
