# 🔡 Refinando a Classificação Tipográfica
A maioria dos tipos podem ser classificados em um dos quatri principais grupos básicos:

- Com Serifas (ou serifadas);
- Sem Serifas;
- Script (ou Cursivas);
- Decorativas

Alguns desses sistemas possuem dezenas de subcategorias.
