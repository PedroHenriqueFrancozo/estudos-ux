# 🔪 Figma: Ferramenta Slice
A ferramenta **Slice** (Fatia) permite isolar e definir áreas específicas do teu layout para exportação, independentemente da estrutura de camadas ou frames.

### 1. Como aceder

- **Atalho:** Tecla S
- **Localização:** No menu superior, clicando na seta ao lado da ferramenta Frame.
