# 🔪 Figma: Ferramenta Slice
A ferramenta **Slice** (Fatia) permite isolar e definir áreas específicas do teu layout para exportação, independentemente da estrutura de camadas ou frames.

### 1. Como aceder

- **Atalho:** Tecla S
- **Localização:** No menu superior, clicando na seta ao lado da ferramenta Frame.

### 2. Para que serve o Slice?
Ao contrário de exportar um Frame inteiro, o Slice é útil quando:

- Precisas de exportar uma parte de uma imagem que atravessa vários elementos.
- Queres exportar um ícone com uma "área de toque" específica (ex: um ícone de 24x24 dentro de uma área invisível de 48x48).
- Precisas de recortar uma secção específica de um ecrã longo para uma apresentação.
